The root `app.js` is the sole Express application that bootstraps the entire platform and registers each domain module through a declarative `modules` array mapping an id, frontend path, and archive directory. All four modules share one SQLite database (`tax_database.db`) accessed via Promise-wrapped `dbGet`/`dbRun`, express-session with bcryptjs for authentication, and Socket.IO for real-time PDF upload progress using the same session cookie. Each module mounts its own static archive directory (`arsip_vatin`, `arsip_vatout`, `arsip_prepaid`, `arsip_payable`) under `/arsip_<module>` routes. Cross-module data consistency is enforced by shared helper functions in `app.js` (`parseStatusFaktur`, `getNoFakturNormal`, `extractMasaPajak`, `bersihkanAngka`) used uniformly across every module's endpoints. Client-side pages load the shared sidebar layout via `fetch('sidebar.html')` and consume global utilities from `toast.js`, `pagination.js`, `utils.js`, and `theme.js`, while server-side middleware (helmet, rate limiting, blocked-file filtering, CSRF protection, JSON/body parsing limits) applies to all modules uniformly.
