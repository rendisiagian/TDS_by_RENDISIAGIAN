No build step — pages are served directly as static HTML. Real-time features require a running Socket.IO server that emits events like `data-baru-vatout`, `update-tabel-vatout`, `upload-batch-selesai` and handles `request-action-faktur`, `upload-pdf-vatout-batch`, `simpan-final-vatout`, `hapus-inbox-vatout`. PDF archives must be placed under `vat_out/arsip_vatout/` following the naming convention `<prefix>_<entity_code>_<id>_<client>.pdf`.
