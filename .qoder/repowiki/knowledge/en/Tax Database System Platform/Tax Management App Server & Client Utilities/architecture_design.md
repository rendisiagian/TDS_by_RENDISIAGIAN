Single-file Express application (`app.js`) owns the entire HTTP server lifecycle: middleware stack (helmet, rate-limiting on `/login`, `express-session` with httpOnly+sameSite cookies, JSON/urlencoded body parsers), SQLite initialization via `sqlite3` with Promise wrappers `dbGet`/`dbRun`, and dynamic module table creation for four business modules (`vatin`, `vatout`, `payable`, `prepaid`) each producing `data_<id>`, `item_<id>`, and `inbox_<id>` tables plus mounted archive directories under `/arsip_*`. Route protection uses two-tier middleware: `cekAuth` checks `req.session.user` existence, while `cekRoleAPI(roles)` enforces RBAC by comparing against an allowed role list. Socket.IO is mounted on the same `http.Server` instance and shares the session middleware via `io.engine.use(sessionMiddleware)`. Two pure client-side utility files are loaded by frontend pages: `export.js` provides a single `exportTableData(tableId, filename, format, ignoreCols)` entry point that branches to modern SheetJS (XLSX) or a legacy HTML-to-XLS fallback, and `pagination.js` exposes `initPagination`/`renderPagination` with global state stored in `window.__pgState` keyed by container ID and callback hooks `__pgGo` / `__pgChangeLimit` invoked through `onPageChange(page, limit)`.
