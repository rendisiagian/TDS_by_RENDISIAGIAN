Single-file Express application (`app.js`) owns the entire HTTP server lifecycle: it configures middleware (helmet, `express-session` with httpOnly+sameSite cookies, JSON/urlencoded body parsers), initializes a SQLite database (`tax_database.db`) via `sqlite3`, creates core tables (`users`, `master_cabang`, `audit_logs`, `data_client_ledger`, `projects`, `porsi_vatout`) and four dynamic module table families (`data_<id>`, `item_<id>`, `inbox_<id>` for vatin/vatout/payable/prepaid) inside a `db.serialize` block, then mounts archive directories under `/arsip_*`. Route protection uses two-tier middleware — `cekAuth` checks `req.session.user` existence and redirects to `/login`, while `cekRoleAPI(roles)` enforces RBAC by comparing `req.session.user.role` against an allowed list. Session middleware is shared with Socket.IO via `io.engine.use(sessionMiddleware)`. Two pure client-side utility files are loaded by frontend pages: `export.js` exposes a single `exportTableData(tableId, filename, format, ignoreCols)` entry point that branches to modern SheetJS (XLSX) when the global `XLSX` library is present or falls back to legacy HTML-to-XLS generation; `pagination.js` exposes `initPagination`/`renderPagination` with global state stored in `window.__pgState` keyed by container ID and callback hooks `__pgGo` / `__pgChangeLimit` invoked through `onPageChange(page, limit)`.
