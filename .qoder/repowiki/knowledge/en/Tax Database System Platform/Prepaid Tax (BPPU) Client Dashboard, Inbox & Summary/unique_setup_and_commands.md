No build step — pages are served directly as static HTML under `prepaidtax_bppu/`. PDF archives must be placed in `arsip_prepaid/` using the `PRE_<id>.pdf` naming convention expected by the dashboard's `link_pdf_lokal` field. Real-time features require the parent application's Socket.IO server to emit events such as `data-baru-prepaid`, `update-tabel-prepaid`, `simpan-final-sukses`, and `upload-batch-selesai`.
