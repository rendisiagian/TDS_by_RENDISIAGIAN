The root `app.js` is the sole Express application that registers all four domain modules through a declarative `modules` array, each mapping an id, frontend path, and archive directory. All modules share a single SQLite database (`tax_database.db`) accessed via Promise-wrapped `dbGet`/`dbRun`, express-session with bcryptjs for authentication, and Socket.IO for real-time PDF upload progress using the same session cookie. Static archive directories (`arsip_vatin`, `arsip_vatout`, `arsip_prepaid`, `arsip_payable`) are mounted under `/arsip_<module>` routes. Cross-module data consistency is enforced by shared helper functions in `app.js` (`parseStatusFaktur`, `getNoFakturNormal`, `extractMasaPajak`, `bersihkanAngka`) used uniformly across every module's endpoints. Each module contributes its own HTML pages but relies on the root's middleware stack for security (helmet, rate limiting, blocked-file filtering), CSRF protection, and JSON/body parsing limits. Client-side pages load shared layout via `fetch('sidebar.html')` and use global utilities from `toast.js`, `pagination.js`, `utils.js`, and `theme.js`.
