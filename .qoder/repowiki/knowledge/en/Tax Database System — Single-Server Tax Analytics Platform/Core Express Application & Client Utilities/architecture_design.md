Single-file Express application (`app.js`) that owns the entire HTTP server lifecycle: middleware stack (helmet, rate-limiting, express-session, body parsers), SQLite database initialization with `sqlite3` (auto-creating tables via `db.serialize`), role-based route guards (`cekAuth`, `cekRoleAPI`), and REST endpoints for master data, VAT invoices, prepaid tax, client ledger, projects, and audit logs. Socket.IO is mounted on the same HTTP server and shares the session middleware. Three business modules are registered dynamically (`vat_in`, `vat_out`, `taxpayable_bppu`, `prepaidtax_bppu`) each with a data table, an items table, and an inbox table. Two pure client-side utility files (`export.js`, `pagination.js`) provide browser-only functionality — `exportTableData` for CSV/XLSX export using the XLSX library with a legacy HTML-table fallback, and `renderPagination`/`initPagination` for server-side paginated views driven by query params (`page`, `limit`). Dependency direction is one-way: the server owns all business logic; frontend pages load these two JS files as helpers.
